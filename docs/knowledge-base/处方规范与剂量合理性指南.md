## 一、处方用量限制（《处方管理办法》第十八至十九条）

### 1.1 处方有效期

| 处方类型 | 有效期 | 特殊情况 |
|---------|--------|---------|
| 所有处方 | 开具当日有效 | 特殊情况下需延长有效期的，由开具处方的医师注明有效期限，但有效期最长不得超过3天 |

### 1.2 处方用量

| 处方类型 | 用量限制 | 延长条件 |
|---------|--------|---------|
| 急诊处方 | 不得超过 **3日** 用量 | 不得延长 |
| 普通处方 | 不得超过 **7日** 用量 | 慢性病、老年病或特殊情况，可适当延长，但医师应当注明理由 |
| 麻醉药品/第一类精神药品 | 门诊一次不超过 **3日** 常用量 | 癌症疼痛患者可不超过7日 |
| 第二类精神药品 | 一般不超过 **7日** 常用量 | 慢性病或特殊情况可延长，医师注明理由 |

### 1.3 处方天数与系统对应

| 系统处方类型 | 枚举值 | 最大天数 | 延长上限 | 延长条件 |
|-------------|--------|---------|---------|---------|
| 急诊处方 | Emergency=1 | 3天 | 3天 | 不得延长 |
| 普通处方 | Normal=0 | 7天 | 84天 | 需填写延长理由（慢性病/老年病） |
| 儿科处方 | Pediatric=2 | 7天 | 84天 | 需填写延长理由 |

## 二、处方书写规则（《处方管理办法》第六条完整引用）

1. 患者一般情况、临床诊断填写清晰、完整，与病历记载一致
2. 每张处方限一名患者用药
3. 字迹清楚，不得涂改；如需修改，应当在修改处签名并注明修改日期
4. 药品名称应当使用规范的中文名称书写，无中文名称的可以使用规范的英文名称书写；医疗机构或者医师、药师不得自行编制药品缩写名称或者使用代号；书写药品名称、剂量、规格、用法、用量要准确规范，药品用法可用规范的中文、英文、拉丁文或者缩写体书写，但不得使用"遵医嘱"、"自用"等含糊不清字句
5. 患者年龄应当填写实足年龄，新生儿、婴幼儿写日、月龄，必要时要注明体重
6. 西药和中成药可以分别开具处方，也可以开具一张处方，中药饮片应当单独开具处方
7. 开具西药、中成药处方，每一种药品应当另起一行，每张处方不得超过5种药品
8. 中药饮片处方的书写，一般应当按照"君、臣、佐、使"的顺序排列；调剂、煎煮的特殊要求注明在药品右上方，并加括号，如布包、先煎、后下等；对饮片的产地、炮制有特殊要求的，应当在药品名称之前写明
9. 药品用法用量应当按照药品说明书规定的常规用法用量使用，特殊情况需要超剂量使用时，应当注明原因并再次签名
10. 除特殊情况外，应当注明临床诊断
11. 开具处方后的空白处划一斜线以示处方完毕
12. 处方医师的签名式样和专用签章应当与院内药学部门留样备查的式样相一致，不得任意改动，否则应当重新登记留样备案

## 三、药品剂量与数量规范（《处方管理办法》第七条完整引用）

### 3.1 法定计量单位

| 类别 | 单位 |
|------|------|
| 重量 | 克(g)、毫克(mg)、微克(μg)、纳克(ng) |
| 容量 | 升(L)、毫升(ml) |
| 国际单位 | IU、U |
| 中药饮片 | 以克(g)为单位 |

### 3.2 剂型单位书写规范

| 剂型 | 单位 |
|------|------|
| 固体制剂（片剂、丸剂、胶囊剂、颗粒剂） | 片、丸、粒、袋 |
| 溶液剂（口服液、注射液） | 支、瓶 |
| 软膏剂、乳膏剂 | 支、盒 |
| 注射剂 | 支、瓶（需注明含量） |

## 四、处方格式标准（《处方管理办法》附件1完整引用）

### 4.1 处方内容三部分

#### 前记
- 医疗机构名称
- 费别
- 患者姓名、性别、年龄
- 门诊或住院病历号、科别或病区和床位号
- 临床诊断
- 开具日期
- **麻醉药品和第一类精神药品处方**还需包含：患者身份证明编号、代办人姓名及身份证明编号

#### 正文
- 以 **Rp** 或 **R** 标示
- 分列药品名称、剂型、规格、数量、用法用量

#### 后记
- 医师签名或者加盖专用签章
- 药品金额
- 审核、调配、核对、发药药师签名或者加盖专用签章

### 4.2 处方颜色规定

| 处方类型 | 颜色 | 右上角标注 |
|---------|------|-----------|
| 普通处方 | **白色** | 无 |
| 急诊处方 | **淡黄色** | "急诊" |
| 儿科处方 | **淡绿色** | "儿科" |
| 麻醉药品和第一类精神药品处方 | **淡红色** | "麻、精一" |
| 第二类精神药品处方 | **白色** | "精二" |

## 五、抗菌药物分级管理（《抗菌药物临床应用指导原则》2015年版）

### 5.1 分级原则

| 级别 | 定义 | 处方权要求 |
|------|------|-----------|
| 非限制使用级 | 经长期临床应用证明安全、有效，对细菌耐药性影响较小，价格相对较低的抗菌药物 | 经注册的执业医师均可开具 |
| 限制使用级 | 经长期临床应用证明安全、有效，对细菌耐药性影响较大，或者价格相对较高的抗菌药物 | 经注册的执业医师，经培训考核合格后方可开具 |
| 特殊使用级 | 具有明显或者严重不良反应，不宜随意使用；抗菌作用强、细菌易产生耐药性；疗效/安全性资料缺乏；价格昂贵的抗菌药物 | 经注册的执业医师，经培训考核合格后开具，使用前需经抗感染专家会诊同意 |

### 5.2 系统管控规则

| 抗生素级别 | 系统枚举 | 管控措施 |
|-----------|---------|---------|
| 非限制使用级 | NonRestricted=1 | 正常开具 |
| 限制使用级 | Restricted=2 | 提示但允许开具 |
| 特殊使用级 | Special=3 | **阻断开具**，需审批后使用 |
| 非抗生素 | None=0 | 无管控 |

## 六、药物相互作用风险分级

### 6.1 风险等级定义

| 等级 | 定义 | 系统处理 |
|------|------|---------|
| Major（严重） | 联合用药可能危及生命或显著降低疗效 | **阻断开具**，禁止联合使用 |
| Moderate（中度） | 联合用药可能产生不良反应，可通过调整剂量管理 | 允许开具，记录审计日志警告 |
| Minor（轻度） | 联合用药可能产生轻微不良反应 | 允许开具，不阻断 |
| Unknown（未知） | 现有证据不足以确定风险 | 允许开具，建议关注 |

### 6.2 常见严重药物相互作用（Major级）

以下为临床常见的Major级药物相互作用，系统必须阻断：

| 药物A | 药物B | 相互作用机制 |
|-------|-------|-------------|
| 华法林 | 阿司匹林 | 增加出血风险 |
| 华法林 | 胺碘酮 | 抑制华法林代谢，增加INR |
| 克拉霉素 | 辛伐他汀 | CYP3A4抑制，增加横纹肌溶解风险 |
| 克拉霉素 | 他克莫司 | 血药浓度显著升高 |
| SSRI类抗抑郁药 | MAOI类抗抑郁药 | 5-羟色胺综合征 |
| 甲氨蝶呤 | 复方磺胺甲噁唑 | 增加骨髓抑制风险 |
| ACEI | 钾保利尿剂 | 高钾血症 |
| 左甲状腺素 | 考来烯胺 | 降低左甲状腺素吸收 |
| 苯妥英 | 异烟肼 | 苯妥英中毒 |
| 地高辛 | 维拉帕米 | 地高辛血药浓度升高 |

## 七、处方保存期限（《处方管理办法》第五十条完整引用）

| 处方类型 | 保存期限 |
|---------|---------|
| 普通处方、急诊处方、儿科处方 | **1年** |
| 医疗用毒性药品、第二类精神药品处方 | **2年** |
| 麻醉药品和第一类精神药品处方 | **3年** |

处方保存期满后，经医疗机构主要负责人批准、登记备案，方可销毁。

### 7.1 电子病历保存期限（《电子病历应用管理规范》第十九条）

| 类型 | 保存期限 |
|------|---------|
| 门（急）诊电子病历 | 自患者最后一次就诊之日起不少于 **15年** |
| 住院电子病历 | 自患者最后一次出院之日起不少于 **30年** |

## 八、药师审核要求

### 8.1 审核内容（《处方管理办法》第三十五至三十六条）

药师应当对处方用药适宜性进行审核，审核内容包括：
1. 规定必须做皮试的药品，处方医师是否注明过敏试验及结果的判定
2. 处方用药与临床诊断的相符性
3. 剂量、用法的正确性
4. 选用剂型与给药途径的合理性
5. 是否有重复给药现象
6. 是否有潜在临床意义的药物相互作用和配伍禁忌
7. 其他用药不适宜情况

### 8.2 审核结果处理（《处方管理办法》第三十六至三十七条）

| 审核结果 | 处理方式 |
|---------|---------|
| 不规范处方 | 不得调剂，告知处方医师，请其确认或重新开具 |
| 用药不适宜处方 | 不得调剂，告知处方医师，请其确认或重新开具 |
| 严重不合理用药或用药错误 | 拒绝调剂，及时告知处方医师，记录并上报 |
| 合格处方 | 调配药品，发药时进行用药交代 |

### 8.3 药师"四查十对"制度

| 查 | 对 |
|----|-----|
| 查处方 | 对科别、姓名、年龄 |
| 查药品 | 对药名、剂型、规格、数量 |
| 查配伍禁忌 | 对药品性状、用法用量 |
| 查用药合理性 | 对临床诊断 |

## 九、特殊人群用药剂量调整

### 9.1 儿童用药剂量计算

| 方法 | 计算公式 | 适用场景 |
|------|---------|---------|
| 按体重计算 | 儿童剂量 = 成人剂量 × 儿童体重(kg) / 50 | 最常用 |
| 按体表面积计算 | 儿童剂量 = 成人剂量 × 儿童体表面积(m²) / 1.73 | 更精确，抗肿瘤药常用 |
| 按年龄折算 | Young's公式：儿童剂量 = 成人剂量 × 年龄 / (年龄+12) | 简易估算 |
| 按年龄折算 | Fried's公式（<1岁）：儿童剂量 = 成人剂量 × 月龄 / 150 | 婴儿 |

### 9.2 老年人用药原则

1. **起始剂量减半**：65岁以上老年人药物代谢减慢，起始剂量通常为成人常规剂量的1/2~2/3
2. **滴定增量**：缓慢增加剂量，密切观察不良反应
3. **用药品种简化**：尽量减少用药品种，避免多重用药
4. **定期评估**：定期评估用药必要性，及时停用不必要的药物

### 9.3 肾功能不全患者剂量调整

| 肌酐清除率(mL/min) | 剂量调整原则 |
|-------------------|-------------|
| >80 | 正常剂量 |
| 50-80 | 正常剂量或轻度减少(75-100%) |
| 10-50 | 中度减少(50-75%) |
| <10 | 显著减少(25-50%)或延长给药间隔 |

主要经肾脏排泄的药物需要调整：氨基糖苷类、万古霉素、二甲双胍、别嘌醇、地高辛等。

### 9.4 肝功能不全患者剂量调整

| 药物类型 | 调整原则 |
|---------|---------|
| 一线代谢药物 | 显著减量或避免使用 |
| 二线代谢药物 | 中度减量 |
| 肾排泄为主药物 | 通常无需调整 |

需特别注意的肝毒性药物：对乙酰氨基酚、异烟肼、甲氨蝶呤、他汀类、抗癫痫药等。

## 十、处方点评制度（《处方管理办法》第四十四至四十五条完整引用）

### 10.1 点评要求

医疗机构应当建立处方点评制度，填写处方评价表，对处方实施动态监测及超常预警，登记不合格处方。

### 10.2 超常处方处理

| 情形 | 处理方式 |
|------|---------|
| 出现超常处方 **3次以上** 且无正当理由 | 提出警告，限制其处方权 |
| 限制处方权后仍连续 **2次以上** 出现超常处方 | 取消其处方权 |

### 10.3 处方权取消情形（《处方管理办法》第四十六条）

医师出现下列情形之一的，处方权由所在医疗机构予以取消：
1. 被责令暂停执业
2. 考核不合格离岗培训期间
3. 被注销、吊销执业证书
4. 不按照规定开具处方，造成严重后果的
5. 不按照规定使用药品，造成严重后果的
6. 因开具处方牟取私利

## 十一、计算机处方特殊要求（《处方管理办法》第二十八条完整引用）

医师利用计算机开具、传递普通处方时，应当同时打印出纸质处方，其格式与手写处方一致；打印的纸质处方经签名或者加盖专用签章后有效。药师核发药品时应当核对打印的纸质处方，无误后发给药品，并将打印的纸质处方与计算机传递处方同时收存备查。
