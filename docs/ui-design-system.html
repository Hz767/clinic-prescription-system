1. 设计理念

"Clinical Clarity" — 临床清晰度设计体系，为基层诊所的日常工作提供高效、安全、可信赖的交互体验

🔍

清晰优先

信息层级分明，关键数据突出显示。医生在繁忙诊疗中能快速定位所需信息。

🛡️

安全导向

过敏警示、药物交互、权限控制等安全要素通过醒目的视觉语言传达，降低误操作风险。

⚡

高效操作

常用功能一步可达，表单输入支持快捷键，处方开具流程不超过3次点击。

🌿

专业信赖

Teal 主色调传递医疗专业感与治愈氛围，界面克制不花哨，符合医疗场景审美。

设计目标
将当前系统从纯功能型界面升级为具有统一视觉语言、专业医疗气质和良好交互体验的产品级UI。配色方案采用医疗 Teal (#0D9488) 作为主色，传递健康、治愈与专业感。

9. 无障碍与可访问性

确保系统对不同角色用户都友好可用

规范要求实现方式
色彩对比度正文文字 ≥ 4.5:1 (WCAG AA)Gray-700 (#374151) on White = 10.3:1 ✓
按钮文字≥ 3:1 (WCAG AA Large)White on Teal-600 = 4.8:1 ✓
焦点指示键盘焦点可见FocusVisualStyle with Teal border
快捷键常用操作支持键盘Enter=确认, Esc=取消, Ctrl+S=保存, Ctrl+P=打印
错误提示不仅依赖颜色图标 + 文字 + 颜色三重提示
角色适配按角色隐藏/显示功能ViewModel 的 CanPrescribe 等属性控制
