# 阶段一：键盘优先交互优化 — 使用说明

> 版本：适用于 v1.1.x | 更新日期：2026-09-16
> 本说明覆盖「键盘优先」交互优化的 4 大类功能：全局快捷键、处方模板、复制上次处方、快捷词快速选择。

---

## 1. 功能总览

本阶段面向"减少鼠标依赖、缩短重复开方时间"的目标，新增以下能力：

| 功能 | 作用 | 使用位置 |
|------|------|----------|
| 全局快捷键 + 导航高亮 | 任何页面按组合键快速切换，并高亮当前所在页面 | 整个主窗口 |
| 常用处方模板 | 把常用处方存为模板，一键套用诊断与全部药品用法 | 处方开具页 · 右侧药品栏顶部 |
| 复制上次处方 | 选中患者后，一键带入该患者最近一次处方 | 处方开具页 · 右侧药品栏顶部 |
| 快捷词数字选择 | 主诉/诊断联想弹出时，按数字键直接添加，Esc 关闭 | 处方开具页 · 主诉/诊断输入框 |

---

## 2. 全局快捷键 + 导航当前页高亮

### 2.1 快捷键体系

- **全局快捷键**（在主窗口任何页面均可使用）：

| 快捷键 | 功能 |
|--------|------|
| `Alt + 1` | 切换到 **工作台**（Dashboard） |
| `Alt + 2` | 切换到 **处方开具** |
| `Alt + 3` | 切换到 **收费结算** |
| `Alt + 4` | 切换到 **库存管理** |
| `Alt + 5` | 切换到 **处方历史** |
| `Alt + 6` | 切换到 **患者管理** |
| `Alt + 7` | 切换到 **病历管理** |

- **处方开具页局部快捷键**（页面聚焦时可用）：

| 快捷键 | 功能 |
|--------|------|
| `F5` | 保存当前处方 |
| `Ctrl + S` | 保存并审核 |
| `Ctrl + N` | 新建处方 |
| `Ctrl + P` | 生成 PDF |

### 2.2 导航高亮

- 切换页面后，左侧导航栏中 **当前所在页面** 的图标与文字会以高亮颜色显示，方便随时确认当前所处模块。
- 主窗口左上角 Logo 区常驻显示提示文本「页面快键：Alt + 1~7」，方便记忆。

> **提示**：快捷键依赖顶部数字键，位于键盘字母区上方的 `1~7` 键（与 `Shift` 组合的数字行），不是小键盘区。

## 3. 常用处方模板（存模板 / 套用）

适用于"开具频率高的常见处方，如感冒、高血压常规用药"，避免反复手选药品。

### 3.1 界面位置

进入 **处方开具** 页面，模板操作面板位于**右侧药品栏顶部**（药品目录列表上方），包含：

- 顶部：**「复制上次处方」** 按钮
- 第二行：模板下拉框 + **「套用」** 按钮 + **「✕」**（删除）按钮
- 第三行：模板名称输入框 + **「存为」** 按钮

### 3.2 保存当前处方为模板

1. 在处方开具页面，正常填写诊断、选择处方类型、添加好全部药品及用法用量；
2. 在右侧模板面板的**名称输入框**中键入模板名称（如"上呼吸道感染常规"）；
3. 点击 **「存为」** 按钮。

保存内容：当前处方的 **诊断文本、处方类型、全部药品及其用法用量（剂量/频次/用法/疗程/数量）**。

### 3.3 套用模板

1. 在模板下拉框中选择一个已保存模板；
2. 点击 **「套用」** 按钮。

系统将模板中的诊断与全部药品用法带入当前处方（若当前已有明细会追加）。

### 3.4 删除模板

1. 在模板下拉框中选择要删除的模板；
2. 点击 **「✕」** 按钮，确认后删除该模板。

### 3.5 存储位置

- 模板按**医生登录名**隔离保存为本地 JSON 文件：`程序目录\usertemplates\{登录名}_templates.json`。
- 属于医生个人界面偏好配置，**不入数据库、不参与业务事务**，仅用于减少重复开方。
- 换机或重装后如需保留模板，可备份 `usertemplates` 文件夹。

> **注意**：模板只保存"开方内容"（诊断+药品），**不保存患者信息、不保存处方编号**，因此不存在患者数据混淆风险。

## 4. 复制上次处方（同患者历史一键带入）

适用于"复诊患者，用药方案与上次基本相同"的场景。

### 4.1 操作步骤

1. 在 **处方开具** 页面选中目标患者（通过门诊病历头部的姓名联想输入框选择）；
2. 点击右侧药品栏顶部的 **「复制上次处方」** 按钮。

系统将自动带入该患者**最近一次处方**的诊断文本与全部药品用法用量。

### 4.2 使用前提

- **必须先选中患者**（未选择患者时按钮不可用）。
- 需要该患者存在 **最近一次处方记录**。
- 带入的关键词：诊断、处方类型、全部药品明细。

> **提示**：复制后仍可对带入的明细进行增删改，再保存为本次处方，与手动添加完全一致。

## 5. 快捷词数字选择（键盘输入加速）

适用于快速录入高频主诉/诊断词，减少逐字输入。

### 5.1 触发方式

- 点击 **主诉输入框** 或 **诊断输入框** 时，下方弹出对应的常见快捷词列表（`Popup` 联想面板）。

### 5.2 快捷键操作

| 按键 | 作用 |
|------|------|
| `数字 1 ~ 9` | 快速选中并添加列表中的第 N 条快捷词 |
| `Esc` | 关闭快捷词弹出面板，直接进行手动输入 |

- 弹出面板处于**打开状态**时按数字键才生效；
- 按 `Esc` 关闭后即可自由输入。

### 5.3 操作流程示例

1. 点击主诉输入框 → 弹出常见主诉快捷词；
2. 看到想要的词条序号 → 直接按对应数字键（如 `3`）→ 该词条被添加到主诉；
3. 如需继续手输其他内容，按 `Esc` 关闭面板后输入。

## 6. 常见问题（FAQ）

**Q1：快捷键没有反应？**
- 全局快捷键 `Alt + 1~7` 需在主窗口聚焦时使用；若焦点在某个输入框内，全局快捷键仍应生效。
- 局部快捷键（`F5` / `Ctrl+S` 等）需停留（聚焦）在处方开具页面使用。

**Q2：模板套用后药品与当前已选药品重复？**
- 套用为追加操作；若已重复添加同一药品，系统会按处方规则（同药拦截）提示，请手动删除重复项后再保存。

**Q3：复制上次处方按钮呈灰色不可点击？**
- 请确认已在门诊病历头部通过联想选择了患者；未选择患者时按钮不可用。

**Q4：模板在其他医生账号下看得到吗？**
- 看不到。模板按医生登录名隔离存储，各账号模板互不影响。

**Q5：快捷词面板弹出但按数字键无效果？**
- 请先确保面板处于**打开**状态；面板打开时按 `1~9` 直接生效，按 `Esc` 才切换到手动输入模式。
