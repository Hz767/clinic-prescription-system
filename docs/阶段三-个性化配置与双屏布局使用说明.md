# 阶段三：个性化配置 · 销量报表 · 双屏布局 — 使用说明

> 版本：适用于 v1.2.x | 更新日期：2026-09-16
> 本说明覆盖阶段三的 3 大类功能：医生个性化配置（快捷词库 / 药品套餐 / 默认用药）、药品销量 Top 报表图表、双屏布局（副屏选药）。

---

## 1. 功能总览

本阶段面向"进一步压缩重复操作、经营数据一目了然、提升录入效率"的目标：

| 功能 | 作用 | 使用位置 |
|------|------|----------|
| 快捷词库可编辑 | 主诉/诊断快捷词按个人维护，增删自定义常用话术 | 处方开具页 · ⚙ 个性化设置 |
| 常用药品套餐 | 把一组常用药品组合存为套餐，一键套用到当前处方 | 处方开具页 · ⚙ 个性化设置 |
| 默认用药预填 | 保存个人默认的频次/用法/用量，新建药品时自动带入 | 处方开具页 · ⚙ 个性化设置 |
| 药品销量 Top 图表 | 按近7天/30天/本月统计销量与销售额排行 | 工作台（Dashboard） |
| 双屏选药 | 把药品选择列表开到副屏，主屏专注录入，数据实时同步 | 处方开具页 · 右侧药品栏顶部「双屏选药」 |

## 2. 医生个性化配置（⚙ 个性化设置）

### 2.1 打开设置面板

进入 **处方开具** 页面，在左侧上方面板底部（或设置开关处）点击 **「⚙ 个性化设置」** 开关，展开个性化配置面板。展开面板分为三部分：**常用药品套餐**、**快捷词 · 主诉**、**默认用药**。

> 所有个性化配置均按 **医生登录名** 隔离保存，换账号登录后互不影响。

### 2.2 常用药品套餐（存组合 / 一键套用）

适用于"一组多药方案（如感冒三联、高血压联合用药）反复使用"的场景。

**添加 / 套用套餐：**

1. 在处方开具页面正常填写好诊断、并添加好一组药品及各自用法用量；
2. 展开「⚙ 个性化设置」→ 点击套餐区右侧的 **「＋」**（新增）按钮，按提示为当前药品明细保存为套餐并命名；
3. 之后开具新处方时，在套餐下拉框 **选择套餐** → 点击 **「套用」**。
4. 系统将套餐中的全部药品及用法用量一次性带入当前处方明细。

**删除套餐：**

1. 在套餐下拉框中选择要删除的套餐；
2. 点击套餐区右侧的 **「✕」** 按钮，确认后删除。

> **提示**：套用为追加操作；若与当前草稿重复，系统会按既有处方规则（同药拦截、≤5 种、天数限制）提示，请按提示整理后保存。

### 2.3 快捷词库可编辑（主诉 / 诊断）

与阶段一的**内置**快捷联想词不同，阶段三允许你自定义个人话术库：

1. 在「快捷词 · 主诉」输入框键入自定义主诉话术（如"咳嗽伴发热3天"）；
2. 点击右侧 **「＋」** 按钮，将其加入个人快捷词库；
3. 快捷词以标签形式展示，点击标签旁 **「✕」** 可移除。

保存后，在主诉 / 诊断联想弹出面板中选择快捷词时，会优先展示你的个人快捷词。删除后同步从联想中移除。

### 2.4 默认用药预填

配置每次添加药品时自动带入的默认用法，减少重复填写：

1. 在处方中先把某一项药品的 **剂量 / 单位 / 频次 / 用法 / 疗程** 调整为常用值；
2. 在「默认用药」区点击 **「保存为默认」**。
3. 此后新建处方、添加药品时，系统会以该组默认值预填用法用量（剂量/单位/频次/用法/疗程/数量）。

> 预填的默认值仍可在当前药品行手动修改，不影响本次处方。仅影响后续新建的药品明细。

### 2.5 存储位置

- 个性化配置按医生登录名保存为本地 JSON：`程序目录\preferences\{登录名}_preferences.json`。
- 属于医生个人界面偏好，**不入数据库、不参与业务事务**，仅用于减少重复开方。
- 换机或重装后如需保留，可备份 `preferences` 文件夹。

## 3. 药品销量 Top 报表图表（工作台）

### 3.1 进入位置

登录后进入 **工作台（Dashboard）** 首页，在 KPI 卡片下方找到 **「药品销量 Top」** 卡片。

### 3.2 时间范围切换

卡片右上角下拉框支持三种统计范围（切换后自动刷新，无需手动点刷新）：

| 选项 | 统计口径 |
|------|----------|
| 近7天 | 最近 7 天成交处方的销量 |
| 近30天 | 最近 30 天成交处方的销量 |
| 本月 | 本月 1 日起至今日的销量 |

> **统计口径**：仅统计**已收费（Paid）或已发药（Dispensed）** 的处方；已作废、已退费的处方自动排除，避免重复计入。

### 3.3 图表解读

- 以条形图展示 **销量 Top 10** 药品；
- 每条左侧为药品名称，右侧显示 `×{数量}` 与 `¥{销售额}`；
- 条形长度按该范围内**最高销售额**归一化，条形越长表示卖得越多/销售额越高；
- 排序优先级：先按销量降序，销量相同时按销售额降序。
- 若区间内无成交数据，卡片显示「暂无销量数据」空态。

> 图表数据随卡片所在页面每次加载或切换范围时自动获取，反映真实成交情况，可用于复盘畅销品种与备货。

## 4. 双屏布局（副屏选药）

适用于"主屏录入处方信息，副屏/第二显示器专注筛选药品"的双屏工作场景。

### 4.1 打开副屏

在 **处方开具** 页右侧 **药品选择** 栏顶部点击 **「双屏选药」** 按钮，弹出**药品选择（副屏）**窗口。

> - 已打开时再次点击会**激活并前置**已存在的窗口（不会重复弹出多个）；
> - 切换页面或离开处方开具页时，副屏窗口会自动关闭；
> - 副屏与主屏**共享同一个 ViewModel**，两侧数据实时双向同步，无需手动刷新。

### 4.2 副屏功能

| 控件 | 作用 |
|------|------|
| 搜索框 | 输入药品名称/规格关键词实时过滤药品列表 |
| 分类下拉框 | 切换筛选范围：全部药品 / 仅抗菌药 / 特殊管理药品 / 低库存预警 |
| 药品列表 | 展示商品名 + 规格 + 参考零售价，**双击**药品行快速添加 |
| 当前药品明细 | 显示主屏当前草稿的全部药品、数量、小计及总金额 |

### 4.3 操作流程示例

1. 主屏填写好患者与诊断；
2. 点击「双屏选药」打开副屏窗口，将窗口拖到第二显示器；
3. 在副屏搜索框输入关键词过滤药品，双击所需药品 → 药品立即出现在主屏明细区；
4. 主屏专注录入其余信息，副屏继续选药；两边明细、金额始终保持一致。

> **注意**：副屏双击添加药品与主屏行为一致，需当前处方已创建草稿。若尚未新建处方或未选中患者，双击会提示先补充必要信息。

## 5. 常见问题（FAQ）

**Q1：个性化设置保存后，其他医生账号能看到吗？**
看不到。快捷词、套餐、默认用药均按登录名隔离保存，各账号互不影响。

**Q2：套餐 "套用" 后药品与当前已选重复 / 超上限？**
套用为追加操作。若与当前草稿重复（同药拦截）或超过 5 种上限、天数超限，系统会提示，请整理明细后再保存。

**Q3：销量 Top 为什么不显示已作废/已退费的处方？**
作废/已退费的处方已从收入口径剔除，销量统计仅计已收（Paid）/已发药（Dispensed）的成交处方，避免重复计入。

**Q4：副屏窗口点不开 / 点了没反应？**
请确认停留在课程方开具页；若窗口已存在并隐藏，再次点击会激活它。切换页面会自动关闭副屏，返回处方页后需重新点击打开。

**Q5：副屏看不到实时更新的明细？**
主副屏共享同一数据源（同一 ViewModel），金额与明细应实时一致；若异常，请关闭副屏窗口后重新点击「双屏选药」打开。
